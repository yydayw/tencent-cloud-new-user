## 常见问题

**新注册的账号就是新用户吗？**

不完全是。新人价主要看“产品首单”，也就是这个账号有没有买过轻量应用服务器，和注册时间关系不大。买过一台就不算首单了。

**38 元和 99 元的 4核4G 有什么区别？**

配置相同：4核4G、3M 带宽、300G 月流量、40G 系统盘。区别在资格和名额：38 元限个人认证的产品首单账号，限量；99 元 OpenClaw 专区产品首单即可，企业账号也能买。

**第二年续费会涨吗？**

续费价格以续费时的页面为准。能确定的是同价续费每个配置只限 1 次，秒杀和买赠档不承诺续费同价。介意的话优先选同价续费档，或者直接买三年套餐。

**代金券能和活动价一起用吗？**

按目前的规则不能，代金券只用于正价订单，活动价订单在支付页无法选券。具体以券面说明为准。

**免费试用会影响之后的首单优惠吗？**

不会。试用和购买占用不同的实例名额，先试用再买，两份都能拿到。

**国内节点一定要备案吗？**

通过国内节点对外提供网站服务需要备案；香港、新加坡等境外节点不需要。
